О проекте

Как работает шифрование и почему это безопасно

🛡️

Алгоритм AES-256-GCM

Используется стандарт AES (Advanced Encryption Standard) с длиной ключа 256 бит. Режим GCM (Galois/Counter Mode) обеспечивает не только конфиденциальность, но и проверку целостности данных.

🔑

Как создаются ключи

В режиме «Случайный код» ключ генерируется через crypto.getRandomValues — криптографически стойкий генератор случайных чисел. В режиме «Пароль» используется PBKDF2 с 310 000 итераций SHA-256.

🌐

100% локально

Файлы никогда не покидают ваш браузер. Всё шифрование и расшифровка происходит на вашем устройстве через Web Crypto API. Нет серверов, нет передачи данных по сети.

🧩

Структура файла

Зашифрованный .enc файл содержит: 12 байт IV (вектор инициализации) + 16 байт соли + зашифрованные метаданные (имя файла) и сами данные с тегом аутентификации.

⚠️

Важно помнить

Код = ключ. Кто получил код — расшифрует файл. Потеря кода = потеря данных навсегда. Нет «восстановления пароля» — это математически невозможно без ключа.

🚀

Технологии

Чистый HTML/CSS/JS без зависимостей. Работает офлайн в любом современном браузере. Требует HTTPS или localhost, так как Web Crypto не активен на file://.
